# Global Pi instruktioner

## Sprog
Svar altid på det sprog du bliver spurgt, medmindre koden kræver engelsk.

## Kodestil
- Foretræk eksplicitte typer fremfor `any`
- Undgå unødvendige kommentarer — koden skal tale for sig selv
- Brug korte, præcise variabelnavne
- Ingen halvfærdige implementeringer — færdiggør altid det der startes

## Workflow
- Læs relevante filer før du foreslår ændringer
- Forklar *hvorfor* ikke *hvad* når du laver ændringer
- Spørg hvis opgaven er uklar frem for at gætte
- Hold diffs små og fokuserede

## Stack (primær)
- PHP, TypeScript/Node, Python, Rust, C/C++, Lua
- Neovim som editor
- Docker til lokale services
- Arch Linux / systemd

## Formattering
- PHP: PSR-12
- TypeScript/JS: Prettier defaults
- Lua: stylua
- Python: ruff
