# Dotfiles handoff

Updated: 2026-08-14 (Europe/Copenhagen)

## Goal

Build a practical, non-opinionated Omarchy-inspired Hyprland desktop for the
ROG Flow Z13. No Claude Code or forced AI applications. Keep configuration
repo-owned under `~/dotfiles` and expose it through symlinks.

## Active architecture

- Hyprland 0.56 Lua entrypoint: `hypr/hyprland.lua`.
- Shared modules: appearance, input, windows, bindings, autostart.
- Hardware module: `hypr/hosts/flow_z13.lua`.
- Monitor layout is generated by `nwg-displays` into `hypr/monitors.lua`, now
  loaded by `hypr/hyprland.lua`. Do not add fixed monitor positions back to the
  host file.
- `~/.config/hypr`, `~/.config/waybar`, `~/.config/mako`, etc. point to repo
  directories. `~/.local/bin/*` helper scripts are also symlinked.
- `~/.zprofile` starts Hyprland automatically on a real TTY login only.

## Important commands

```sh
~/dotfiles/bin/dotfiles-check
~/dotfiles/bin/dotfiles-install --check
~/dotfiles/bin/dotfiles-install --link
~/dotfiles/bin/dotfiles-install --activate
~/dotfiles/bin/dotfiles-install --setup       # packages + links + tools
~/dotfiles/bin/dotfiles-install --z13         # Z13 package/build/setup
~/dotfiles/bin/dotfiles-install --autologin   # systemd tty1 autologin
```

`--setup`, `--z13`, and `--autologin` require sudo in the user's terminal.
Never use broad destructive cleanup; only remove exact temporary build dirs.

## Current working desktop

- Super+Space: launcher.
- Super+K: searchable keybinding list.
- Super+Alt+Space: system menu (Z13, Bluetooth, audio, displays, theme,
  wallpaper, lock, suspend, logout, reboot, poweroff).
- Super+B: hide/show Waybar.
- Super+V: toggle floating/tiling for the focused window.
- Super+M: minimize the focused window (moves it to a hidden special workspace).
- Super+Alt+M: show/hide minimized windows (they appear as floating).
- ROG GUI: press Super+R, release Super, then O, then G; alternatively click
  the Z13 Waybar field or run `z13gui`.
- `Super+Alt+Space -> Skærme` opens `nwg-displays`.
- `Sluk intern skærm` / `Tænd intern skærm` disable/re-enable the `eDP-1`
  monitor (so it leaves the Waybar workspace list) and toggle DPMS.
- `monitor-hotplug` automatically enables `eDP-1` when all external monitors
  disappear and restarts Waybar when the monitor set changes. It never disables
  the internal screen itself.
- Focus follows mouse is disabled (`input:follow_mouse = 0`): the mouse can
  move away while typing, and scrolling still works on the hovered window.

## Waybar

- Network module shows live download/upload using Waybar bandwidth fields and
  updates every second. Left-click opens `wifi-menu`; right-click opens
  `nm-connection-editor`.
- Ethernet currently appears as `Ethernet`; the dock interface is technically
  named `enp198s0f3u1u1`.
- The bar shows only on the primary display. `waybar-launch` resolves the
  primary via `primary-monitor` (largest external when docked, else `eDP-1`),
  injects `output` into a runtime config and (re)starts Waybar; `monitor-hotplug`
  re-runs it when the monitor set changes.
- Z13 module reads `z13ctl`, CPU load/temp from `k10temp`, GPU load/temp from
  AMDGPU sysfs/hwmon, and RAM from `/proc/meminfo`.
  Example: `Z13 balanced · CPU 4% 48°C · GPU 1% 46°C · RAM 12%`.
- A `custom/minimized` module shows `󰖰 N` when windows are minimized; clicking
  it toggles the minimized windows back into view.
- Brightness module was intentionally removed from the bar.
- Blueman connection popups are hidden by Mako criteria.

## Z13 daemon status

The correct source of truth is the user systemd service:

```sh
systemctl --user status z13ctl.service
z13ctl status
```

`z13ctl.service` is enabled and runs `~/.local/bin/z13ctl daemon`. The old
manual `z13ctl daemon` line was removed from `hypr/autostart.lua` to avoid a
race with the socket. `z13ctl.socket` is retained as a repo link but is not the
active daemon path; the service owns `/run/user/1000/z13ctl/z13ctl.sock`.

## Network, Bluetooth, audio, settings

- NetworkManager and `network-manager-applet` are present; Ethernet through the
  ThinkPad dock is connected and WiFi scanning works (`nmcli device wifi list`).
- `wifi-menu` uses Fuzzel + nmcli and asks for a password for new networks.
- Bluetooth base packages, PipeWire, pipewire-pulse and WirePlumber are present
  in the package plan. Verify/enable in a real terminal if needed:

```sh
sudo pacman -S --needed blueman nwg-displays pavucontrol
sudo systemctl enable --now bluetooth
systemctl --user enable --now pipewire pipewire-pulse wireplumber
```

- Waybar audio clicks open `pavucontrol`; right-click toggles mute.
- `nwg-displays` is the display settings GUI and now actually controls the
  loaded `hypr/monitors.lua` layout.

## Browser decision

Recommended practical default: Firefox, with Google as the search engine and
DRM/Widevine enabled. Keep Chromium/Chrome as an optional compatibility
fallback. LibreWolf is not recommended as the primary browser here because its
hardening caused timezone/video/DRM friction for this user; Google can be added
manually, but practicality wins.

## Validation

`./bin/dotfiles-check` currently passes shell syntax, JavaScript, Waybar JSON,
Hyprland Lua parsing and whitespace checks. Run it after every config change.
